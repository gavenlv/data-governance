# 调研方法与可信度说明

> 本目录的 5 份调研报告是设计文档 `docs/06`–`18` 的事实基础。使用前请先读本页，避免误用。

---

## 1. 调研方法

| 项 | 说明 |
|---|---|
| 时间窗口 | **2026 年 10 月**为基准（含 2024–2026 的市场变化）；产品能力与版本以该时点的公开资料为准 |
| 一手来源优先级 | 官方文档 > 官方博客/规范仓库 > GitHub 仓库与 issue > 第三方评测/对比文章 > 社区问答 |
| 覆盖对象 | 开源（OpenMetadata、DataHub、Atlas、Amundsen、Marquez、Gravitino、sqlglot/OpenLineage/OpenFGA 等库与标准）+ 商业（Collibra、Alation、Informatica、Atlan、Select Star、Datafold、Monte Carlo、Bigeye、Microsoft Purview、Google Dataplex/Knowledge Catalog、AWS Glue/DataZone、国内 DataWorks/DataLeap/WeData 等）+ 标准（OpenLineage、ODCS、Data Product 规范、Iceberg REST 等） |
| 每家的调研维度 | 定位与客户、商业模式与价格、功能清单、**差异化所长**、弱点与客户抱怨、技术实现线索、可复用性判断 |

## 2. 可信度标注约定

调研文档中所有关键事实按以下三档标注，读时请注意语气差异：

| 标注 | 含义 | 使用建议 |
|---|---|---|
| 直接陈述 + 来源链接 | 官方文档/规范/仓库可验证 | 可直接引用 |
| 「**待核实**」 | 检索环境无法取得正文，或数值随版本变化 | 引用前必须查官方最新文档 |
| 「工程经验」/ 推断性结论 | 基于架构推导而非明文声明 | 仅作为设计判断的参考，不作为事实引用 |

## 3. 本次调研的已知局限（重要）

1. **网络出口受限**：本次调研的检索环境**无法直接抓取网页正文**，部分结论基于官方文档的公开知识 + 检索到的官方 URL 交叉印证。因此：
   - 所有**易变数字**（star 数、贡献者数、连接器精确数量、最新版本号、具体报价）均标注「待核实」；
   - **机制性结论**（架构、模型、事件流、存储职责划分）可信度较高，因为它由官方架构文档与仓库结构共同支撑。
2. **商业产品的功能边界**随版本频繁变化，且 open-core/分版本（OSS vs 企业版 vs 云版）差异常被宣传材料模糊处理。
3. **价格信息**绝大多数不公开，文档中只保留"计费口径"（按资产数/席位/用量）而非具体数字。
4. **国内厂商**能力与版本差异大，且公开技术资料少，其调研结论以"能力定位"为主，技术实现线索较薄。
5. 结论中的能力评分是**"设计中位水平"的判断**（●/◐/○/—），不是精确测量，用于定位而非审计。
6. **字数的测量口径（踩过的坑，务必沿用正确方法）**：本仓库曾用 PowerShell 的 `Get-Content -Raw` 统计文档长度，但在本环境默认代码页下它会把 **UTF-8 文件按 GBK 解码**，使中文长度**虚高约 1.7 倍**——这曾导致调研文档被错误判定为"字数严重超标"，并触发多轮无谓压缩。**正确做法**：
   ```powershell
   $t = [System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8)
   $han = ([regex]::Matches($t, '[\u4e00-\u9fff]')).Count   # 汉字数
   ```
   任何"是否符合字数要求""是否需要精简"的判断，都必须基于这个口径。

## 4. 使用建议

- **目录结构说明**：`01`–`05` 是五份调研主文档；`04-standards-and-tech.md` 因内容量大，实现细节（逐项来源、参数、代码片段）拆到同名的 `04-standards-and-tech-appendix.md`；`_raw/` 保存各批次的原始取证底稿（含 600+ 来源 URL），供追溯与复核，日常阅读不必打开。
- **做技术选型**：只看 §"架构与实现原理"与 §"关键设计决策与取舍"，并忽略具体数字。
- **做竞品对比/汇报**：可用 §"差异化所长"与 §"弱点"，但对外引用前必须补一次官方核对（尤其是商业产品）。
- **做设计决策**：以本套设计文档（`06`–`18`）为准；调研文档只提供"别人怎么做的"素材，不直接构成我们的决策。
- **发现错误**：调研文档均标注为 Draft，欢迎在可联网环境下补齐「待核实」项并更新版本号。
